# Probate summary recovery import

Adds automatic recognition of case-summary CSVs alongside the existing Clerk party-row format. Requires Case Number, Case Type, Decedent, Decedent Listed Address and Verification Status. Original normalized fields are preserved in separate case summaries with import-source references. No court party, verified property, parcel link, outreach consent or evidence score is inferred from a summary. Original screening scores remain source metadata only. Existing notes, suppression status, verification and links survive merges; exact repeated rows merge source references without duplication. Case details support search and export of original summary fields. Owner API workspace validation rejects malformed summaries; existing backups remain compatible.
